# Olympic Games Power BI Dashboard

A premium Olympic-themed Power BI dashboard project featuring six interactive report pages built with Power Query, DAX, and a custom dark navy-blue design.

## Features
- 6 interactive dashboards
- Dark Olympic-inspired UI
- KPI cards with neon styling
- Time-based analysis using a Calendar table
- Country, athlete, sport, host, and demographic insights

## Dataset
- Olympic_Athlete_Bio
- Olympic_Athlete_Event
- Olympic_Games_Medals
- Olympic_Results
- Olympics_Country
- Olympics_Games

## Data Preparation
- Cleaned data in Power Query
- Built relationships
- Created a Calendar table
- Created a Measure Table
- Reconstructed incorrect historical Olympic dates using Year and competition date

## KPIs
- Total Medals
- Total Countries
- Total Athletes
- Total Events
- Total Sports
- Olympic Editions
- Gold, Silver, Bronze Medals
- Medal Efficiency
- Average Age
- Male vs Female Participation

## Tools
- Power BI
- Power Query
- DAX

## Design
- Navy blue Olympic theme
- Neon cyan borders
- Purple gradients
- Rounded KPI cards
